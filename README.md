# 绣花制版与针迹仿真系统

浏览器内运行的电脑绣花制版（打版）与针迹仿真系统，TypeScript + WebGL2 + React 实现。
无需安装老版本制版软件，改线色、调针法参数后针迹实时重算，所有数据保存在浏览器本地（IndexedDB）。

## 功能模块

| 页面 | 能力 |
| --- | --- |
| 花版库 | 新建 / 复制 / 删除花版，自动保存，导入导出 Tajima DST，缩略图预览 |
| 制版编辑 | 手绘多边形轮廓、位图自动描边分区；平针 / 缎纹 / 榻榻米针法；针迹方向、密度、拉线补偿、底衬针实时调整；绣制顺序自动排程与手动调整；历史版本快照与差异对比 |
| 针迹仿真 | 严格按针序逐针动画、速度调节、进度拖拽；跳针（金）与换色点（品红）标记；丝线各向异性光泽；布面拉伸起皱模拟；起坨密度告警 |
| 生产单 | 多花版拼版自动换行、用线量分色汇总（含 15% 损耗备线建议）、车间纸样 SVG 导出 |
| 线色库 | 内置 16 色常用涤纶丝线，可自定义颜色与光泽度 |

## 快速开始

```bash
npm install
npm run dev        # 开发服务器
npm test           # 单元测试（39 个，含 1000 组 DST 随机 round-trip）
npm run build      # 类型检查 + 生产构建
```

## 架构

```
src/
├─ dst/           DST 二进制解析与写回（最关键，正确性由测试锁定）
├─ core/          领域类型、几何（扫描线/多边形）、针法参数、统计、排程
├─ stitches/      分区→针迹编译器（平针/缎纹/榻榻米/底衬）
├─ trace/         位图二值化→连通域→Moore 轮廓→DP 抽稀
├─ render/        WebGL2 渲染引擎（丝线光泽、走针动画、热力图）
├─ storage/       IndexedDB 持久化（idb）
├─ production/    拼版、用线量、纸样 SVG
├─ store.ts       状态中枢（useSyncExternalStore + 防抖自动保存 + 编译缓存）
└─ pages/         五个页面的 React 组件
```

### 坐标与正确性约定

- 内部全程使用 DST 整数单位（1 单位 = 0.1mm），仅几何中间过程用浮点，编译针迹时统一取整，杜绝浮点漂移。
- DST 位移用平衡三进制（1/3/9/27/81）编码，保证 [-121,121] 内整数位移精确表示；超长移动自动拆条，中间过渡记录抬针。
- 仿真走针顺序 = 编译器输出顺序 = 写入 DST 的记录顺序，三者一致，不做任何重排。
- DST 头部只支持 ASCII，中文花版名在写文件时净化为合法字符（界面显示仍用原名）。

### DST round-trip 保证

`test/dst.test.ts` 包含：
- 全位移空间 encode→decode 无损；
- 1000 组随机路径（单记录步长）逐针 `toEqual` 零误差；
- 解析→写回→再解析幂等；
- 长移动拆分的终点、中间跳针标志、总位移校验；
- 头部针数不符时告警但不阻断。

## 已知边界

- 位图描边针对色块/线条图案，照片级复杂图像需先做二值化预处理。
- 目前支持 Tajima DST 单格式；PES/EXP 等其他格式可在 `src/dst` 同构扩展。
- 纸样导出为 SVG（矢量、可直接打印），PDF 导出可基于 SVG 后续接入。
