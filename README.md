# 绣花制版仿真系统

浏览器内的绣花制版 + 针迹仿真系统,TypeScript + WebGL2,无后端,数据全部保存在浏览器 IndexedDB。

## 运行

```bash
npm install
npm run dev      # 开发服务器
npm test         # DST 编解码 / 针迹生成 / 集成测试
npm run build    # 生产构建
```

## 四个页面

| 页面 | 功能 |
|------|------|
| 花版库 | 新建/复制/删除花版,导入导出 DST,自动保存,历史版本与两版针迹差异对比 |
| 制版编辑 | 位图导入自动描边分区(k-means 量化 + marching squares),手动画轮廓,分区设平针/缎纹/榻榻米,调方向/密度/拉线补偿,改完实时重算,手动或自动排绣制顺序 |
| 针迹仿真 | WebGL2 按绣制顺序动画走针,调速/拖进度,跳针换色标记,绣线光泽随针迹方向变化,起坨警告,布面拉伸起皱模拟,针数与工时统计 |
| 生产单 | 分色用线量核算,多花版拼版,导出车间纸样图 PNG 和生产单 CSV |

## 关键设计

**DST 编解码(`src/core/dst.ts`)** — 精度优先:
- 512 字节定长头(LA/ST/CO/±X/±Y/AX/AY/PD),记录 3 字节定长
- 位移分解为 ±1/±3/±9/±27/±81(0.1mm)加权和,单记录上限 ±12.1mm,超出自动拆分
- 第 3 字节 bit0/1 恒置 1,bit7 跳针,bit6 换色,`00 00 F3` 结束
- DST 的 +X 朝左,读写时对 X 取反;内部坐标 mm、Y 向上
- 往返测试保证针数与坐标在 0.1mm 精度内一致(`tests/dst.test.ts`)

**单一数据源** — `buildPatternStitches()` 生成的针迹序列(含跳针/换色记录)同时供仿真渲染和 DST 导出使用,顺序一致由集成测试保证(`tests/integration.test.ts`)。

**针迹生成(`src/core/stitchgen.ts`)**:
- 平针:轮廓按针距重采样
- 缎纹:扫描线垂直于针迹方向,每条横贯线段一针
- 榻榻米:平行扫描线蛇形填针,奇偶行错位半针
- 拉线补偿:轮廓沿法线外扩;孔洞在扫描线求交时扣除

**渲染(`src/render/gl.ts`)**:每条针迹一个实例化四边形,顶点着色器按方向展开,片元着色器按"针迹方向 × 光源方向"算光泽;布面拉伸用密度梯度位移场纹理在顶点着色器里偏移;绘制实例数 = 仿真进度,天然保证走针顺序。
