# 绣花制版仿真系统

浏览器里的电脑绣花制版 + 针迹仿真系统。TypeScript + WebGL2，纯前端，数据自动保存在浏览器 IndexedDB，无需服务器。

## 运行

```bash
npm install
npm run dev      # 开发
npm run build    # 构建到 dist/
```

## 功能

**花版库**
- 新建 / 复制 / 删除花版，自动保存到浏览器本地
- 导入 DST：按跳针/换色切块为针迹块，针数、坐标、走针顺序与文件完全一致
- 导出 DST：512 字节标准头 + 3 字节针迹记录，超程自动拆段

**制版编辑**
- 导入位图自动描边分区（k-means 颜色聚类 → 轮廓追踪 → 多边形）
- 手动画轮廓（单击加点，双击/回车闭合，Esc 取消）
- 分区针法：平针 / 缎纹 / 榻榻米；可调针迹方向、密度行距、针迹长度、拉线补偿，改完实时重算
- 自动排序：按颜色分组 + 最近邻，减少换色和跳针；也可手动 ↑↓ 调整
- 起坨警告：落针密度超阈值的位置红圈标出
- 历史版本：保存快照、恢复、两版针迹差异对比（红=仅A版，绿=仅B版）

**针迹仿真**
- 按绣制顺序动画走针，速度可调（10–1500 针/秒），进度条/时间轴可拖
- 时间轴标注跳针（蓝）、换色（橙）、起坨（红）
- 丝线光泽随针迹方向变化（WebGL2 着色器），近看能分出每一针
- 布面拉伸起皱模拟（强度滑块）

**生产单**
- 总针数 / 跳针 / 换色 / 尺寸 / 预计工时（机速可设）
- 分色用线量估算（面线 ×1.25 损耗，底线另计）
- 拼版：多花版多拷贝阵列，导出拼版 DST
- 导出车间纸样图 PNG（外框 + 十字定位 + 起针点 + 尺寸标注）

## DST 精度说明

`src/core/dst.ts` 是系统的关键模块，已用随机路径往返测试验证：
- dx/dy 用 ±1/±3/±9/±27/±81 平衡三进制分解，[-121,121]（0.1mm）全量程无损
- 超程移动自动拆成多条记录，落点不变
- 零位移针迹照常写出，保证针数与文件头 ST 标称一致
- 读侧兼容 0x80/0xC0 两种普通针标志、0x1A EOF 填充、尾部零填充

```

              geometry.ts imaging.ts（位图描边）importer.ts diff.ts threadlib.ts types.ts
  store/      store.ts（状态+自动保存）db.ts（IndexedDB）
  render/     gl.ts（WebGL2 针迹渲染器：实例化线段 + 方向光泽 + 起皱位移）
  pages/      library.ts editor.ts simulate.ts production.ts
```
